What would make these genuine recommendations?

A live listings provider would supply real venues, permitted photographs, review counts, price guidance and available opening information. We would show the source and explain why a place matches your choices.

AI could summarise that evidence. It should never invent a review, a visit or an allergy guarantee. Availability, dietary arrangements and access would still need checking with the venue.

This experiment makes no paid API calls and does not change the main app’s GPS, AI or voice settings. Your location is used only in this page to build an external search link; the app does not store it. Google receives the search if you open that link.
